# ShushDJX - Automatically skip `Up next` spoken segments from Spotify's DJ.

## OBSOLETE

This app had a single purpose: avoid having to listen to Spotify's "DJ
X" speak its introductions/summaries/commentary between sets of songs.

As of at least 2026-Nov-21, the Spotify Android app now has a
three-dot menu entry in the player screen (while playing DJ) titled
"DJ commentary" and tapping it offers an option for "Don't break the
flow" which accomplishes the old goal of this app, so it's now
deleted.

For posterity, the last pre-deletion version was [v0.4](https://github.com/fischman/ShushDJX/tree/v0.4) and the
last commit (after that release) was [759c81e1](https://github.com/fischman/ShushDJX/commit/759c81e1aecb5887f7f702386daea4c8fa8fc6b2).
